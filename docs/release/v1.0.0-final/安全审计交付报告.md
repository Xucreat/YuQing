## 2. RBAC 收敛

- 权限码 89、角色 5、角色-权限关联 131，矩阵完整，role_permissions 无孤儿。
- `user_roles` 表为空：生产账号授权经由代码/默认角色路径解析，需明确“账号→角色”绑定方式，避免权限判定依赖隐式路径（见遗留问题清单）。
- 超管 `admin` 走独立校验分支，非动态角色用例覆盖对象。

## 3. 数据库身份门禁（DB Identity Gate）

- 测试基础设施 `tests/conftest.py` 在导入期强制 `DATABASE_URL` 指向隔离测试库 `opinion_test@:5433`，并对非 `opinion_test` 目标直接抛错，阻止误连生产库。
- `test_rbac_hardening.py` 增加生产库探测守卫：当 `DATABASE_URL`/engine 指向 `opinion_db` 时模块级 `pytest.skip`，避免导入期误连生产库。
- 门禁联动：测试库为独立 cluster（system_identifier 不同）时，身份门禁会中止，测试显式关闭门禁（`DB_IDENTITY_CHECK=off`）以适配已知安全场景。

## 4. 测试库隔离

- 测试夹具统一指向 `opinion_test@:5433`，与生产 `opinion_db@:5432` 物理隔离。
- 本冻结环境未启动 `:5433` 测试库，故仅做 collection 验证，未对生产库执行任何测试用例（满足“禁止指向生产库运行测试”约束）。

## 5. 仓库敏感文件扫描

- 已确认 `.env` 不在跟踪集中；`.gitignore` 已覆盖 `.env`、`.env.local` 及批量诊断/临时目录。
- 本次新增 `/tmp/` 忽略规则，防止浏览器凭据缓存误入库。
- 归档前最终扫描见《MANIFEST》与验收报告的安全项。

## 6. 结论

凭据不入库的目标基本达成；唯一残留风险为工作区 `tmp/` 物理凭据缓存（已忽略未跟踪，待人工清理与轮换）。RBAC 与测试库隔离机制到位。**条件允许冻结，但 `tmp/` 凭据须在执行归档分发前清理。**

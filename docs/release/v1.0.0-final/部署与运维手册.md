# 舆情监测系统 v1.0.0 部署与运维手册

> 冻结提交：`4cbf2fa578f42ef1e3eb44c3e4843a1a0653d712`

## 1. 运行环境要求

| 组件 | 版本 |
|---|---|
| Python | 3.13.x（后端 venv） |
| Node | 22.x（前端构建） |
| PostgreSQL | 16 |
| FastAPI / Uvicorn | 0.115.0 / 0.30.6 |
| Vue / Vite | 3.5.12 / 5.4.10 |

## 2. 数据库准备（部署迁移）

1. 在目标 PostgreSQL 实例创建数据库 `opinion_db` 与角色（凭据来自部署用 `.env`，**不得**与开发/测试库共用）。
2. 执行 Alembic 迁移追平：`alembic upgrade head`（当前 head：`opinion_url_text_v1`，共 82 个迁移，单一 head）。
3. 校验：`select version_num from alembic_version;` 应为 `opinion_url_text_v1`。
4. 初始化角色/权限矩阵与种子数据（按项目 seed 脚本）。
5. 禁止在本环境对生产库执行 `pg_restore` 覆盖；恢复须在与生产隔离的实例进行。

## 3. 后端启动

```powershell
cd backend
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

- 健康检查：`GET /health` → `200 {"status":"ok","collector_discovery":"db_driven",...}`
- API 文档：`/docs`（Swagger）、`/redoc`

## 4. 前端构建与托管

```powershell
cd frontend
npm install
npm run build      # 产物写入 frontend/dist
```

- 生产态：构建产物由后端 `backend/app/static` 托管，前后端同源访问。
- 开发态：`npm run dev` 监听 5173（默认不启用）。容器端口约定见 `docker-compose.yml`（8080）。

## 5. 配置与凭据

- 所有敏感配置经 `.env` 注入；`.env` 已被 gitignore，仅 `.env.example` 入库。
- `DATABASE_URL` 必须指向生产/部署库；测试必须指向独立 `opinion_test@:5433`（由 `tests/conftest.py` 强制）。
- 默认 admin 口令已过期，部署后须通过改密流程设置强口令；禁止将口令写入代码或文档。

## 6. 调度

- 采集调度由 APScheduler 驱动，默认对 `enabled` 且 `schedule_enabled` 的数据源按 `schedule_interval_minutes` 执行。
- 外网采集调度为 opt-in，默认关闭；启用需经后端批准范围与权限校验。

- FastAPI 后端 + Vue3 前端（构建后由后端静态托管）的舆情采集/治理/研判/事件/预警平台。
- RBAC 角色权限矩阵收口（89 权限码 / 5 角色 / 131 关联），非超管 403 边界清晰。
- 统一预警中心（境内告警、外网告警、外网告警规则）。
- 调度采集（APScheduler）、任务去重与冲突保护、数据源配置化驱动。
- Alembic 迁移追平至 `opinion_url_text_v1`（82 个迁移，单一 head）。

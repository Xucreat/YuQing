## 5. 发现的异常（仅报告，未修复）

### A1（高）：大厂县政府网站 100% 采集失败
- 错误：`TypeError: GovernmentCollector.fetch() got an unexpected keyword argument 'region_kw'`
- 根因：`service.py` 对**所有**采集器统一注入 `keywords= / region_kw= / topic_kw=`（约 L355），但 v1 设计中 government 保持全量、`GovernmentCollector.fetch(self, keywords=None)` 签名未加 `region_kw/topic_kw` 参数 → 唯一 gov_site 类型源（data_source id=1 大厂县政府网站）每次运行必失败。
- 时间线：今日 17:30 run 仍 success，**19:00 起（run#7444）连续失败**——即 v1 代码在前次 uvicorn 加载后就已存在该问题，属 v1 实施遗漏（测试未覆盖 GovernmentCollector 装配路径），非 Option C 引入。
- 影响：大厂县政府网站源自 19:00 起零采集；其他 15 源不受影响。

### A2（中）：国家级源主题兜底噪声偏高
- 见第 4 节。11/11 无地域关联入库，宽泛主题词（民生/教育）在长正文中命中率过高。
- 可选方向（待授权，另行设计）：主题词命中范围限标题、收紧宽泛词、或国家级源主题词单列子集。
